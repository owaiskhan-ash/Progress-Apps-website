01

Widget first

A transparent ring for every project, sitting on the launcher. Add the widget again for another project; each instance is configured on its own.

02

Milestones & reminders

Tap + on the ring to log a percentage and a note, then set a local reminder if you want one. Tap a milestone to edit it, or use the project menu for history, undo, rename and deadline.

03

Only what’s needed

No account, no sync, no analytics. Projects, milestones and reminders stay on the phone. The whole app is 37 kilobytes.
